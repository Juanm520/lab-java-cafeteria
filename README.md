# lab-java-cafeteria

# JuanM520

Katas Java

Ejercicios de Java para practicar lógica de programación con problemas de una cafetería.

Contenido

«Kata 1: Calculadora de propinas
Kata 2: Clasificador de bebidas
Kata 3: Pedidos con IVA
Kata 4: Validador de horarios
Kata 5: Menú interactivo
Kata 6: Clientes por hora
Kata 7: Factura con descuentos
Kata 8: Planificador de turnos»

Conceptos

«Variables y tipos de datos
Operadores y condicionales
Bucles "while", "do-while" y "for"
Entrada con "Scanner"
Salida con "System.out.println()"»

Ejecución

Cada kata debe estar en un archivo independiente: "Kata1.java", "Kata2.java", etc.

«Las katas 1 a 6 son obligatorias.
Las katas 7 y 8 son opcionales.»
